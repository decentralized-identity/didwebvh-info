# The `did:webvh` DID Method Specification

The `did:webvh` specification is published by the [Decentralized Identity
Foundation (DIF)](https://identity.foundation). It is the authority on how
`did:webvh` works. If anything on this site disagrees with it, the
specification is right.

## Current Version: v1.0

**v1.0 is the current, stable version of `did:webvh`.** Use it for
implementations and deployments.

[Read the did:webvh v1.0 Specification :material-open-in-new:](https://identity.foundation/didwebvh/v1.0/){ .md-button .md-button--primary target="_blank" rel="noopener" }

<https://identity.foundation/didwebvh/v1.0/>

## Editor's Draft

The Editor's Draft is where the [DIF `did:webvh` Work Item][work-item] works towards the
next version of the specification. It can change at any time, so don't
implement from it unless you are following the Work Item's discussions.

[Read the did:webvh Editor's Draft :material-open-in-new:](https://identity.foundation/didwebvh/next/){ .md-button target="_blank" rel="noopener" }

<https://identity.foundation/didwebvh/next/>

## Specification Source

The specification source is in the [decentralized-identity/didwebvh]
repository on GitHub. Use the repository to raise issues, read the
discussions, and propose changes by pull request.
